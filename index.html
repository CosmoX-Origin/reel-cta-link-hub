For creators: add a new CTA in 2 minutes

  1. Drop the resource file in resources/, for example resources/NEWWORD.md.
  2. Add one entry to resources.json: word, title, description, status and file.
  3. Rebuild this page or add the entry directly to the index. Keep only this hub's link in the bio, not a separate link for every reel.

Rule: if a resource is not ready, keep its status as coming-soon. Never give a fake link.
