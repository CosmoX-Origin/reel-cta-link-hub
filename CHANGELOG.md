# Changelog — Reel CTA Link Hub

All notable changes to this hub are listed here, newest first.

## v1.5 — 2026-10-25 — English only, everywhere

- Changed: the whole hub page is now English only. All Hinglish UI text
  (header, card descriptions, creator section) was translated to English
  and the Hindi summaries were removed. Resource guides were already in
  English and are unchanged.

## v1.4 — 2026-10-25 — 500 examples, keywords, social footer

- Added: 500 examples (50 per resource), 250 keywords (25 per resource),
  searchable on the hub page, plus meta keywords.
- Added: social links in the footer (Instagram, Facebook, Website, GitHub).
- Note: GitHub allows at most 20 repository topics, so 20 topics are live.

## v1.3 — 2026-10-25 — All discovered features

- Added: SYSTEM (one-person company checklist), NUMBER (Claude WhatsApp
  number setup), ENGINE (content machine setup checklist). No word is
  coming-soon anymore in this version.
- Added: category filters (All, AI Tools, Business, Content) on the hub page.
- Added: one-line Hindi summary for every resource.
- Added: dark mode toggle on the hub page (saved in the browser).
- Added: Share button per resource, and Copy section buttons inside every
  expanded resource.
- Added: GitHub Pages live site (see README), repository topics, and this
  changelog.
- Added: issue template to request a new resource.

## v1.2 — 2026-10-25 — Installation guide

- Added: INSTALL.md, covering no-install reading, ZIP download, git clone,
  Claude usage, MOTION template preview/render, Fork, and troubleshooting.
- Linked INSTALL.md from README and from the hub page footer.

## v1.1 — 2026-10-25 — Trending upgrades

- Added: MIT LICENSE, CONTRIBUTING.md, README stars/license badges and a
  Star request.
- Added: resources/motion-template.html + resources/fonts/montserrat-var.ttf,
  completing the MOTION guide's template promise.

## v1.0 — 2026-10-25 — First public release

- Launched the hub with 7 ready resources: MOTION, COACH, AUDIT, CLAUDE,
  LEADS, SOLO, TEAM. NUMBER was listed as coming-soon.
- Hub page with word search, View, Copy text, and Open file per resource.
- resources.json manifest so other tools can read the hub.
